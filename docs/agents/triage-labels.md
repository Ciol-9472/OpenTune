# 分类标签

技能使用五个规范分类角色的术语。此文件将这些角色映射到此仓库的 issue tracker 中使用的实际标签字符串。

| mattpocock/skills 中的标签 | 我们 tracker 中的标签 | 含义                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此 issue  |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | 完全指定，准备好让 AFK 代理接收  |
| `ready-for-human`          | `ready-for-human`    | 需要人类实现            |
| `wontfix`                  | `wontfix`            | 不会采取行动                     |

当技能提到角色时（例如"应用 AFK 就绪分类标签"），使用此表中对应的标签字符串。

编辑右列以匹配你实际使用的任何词汇。
